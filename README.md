# J.A.R.V.I.S — Android

Groq AI + ElevenLabs TTS tabanlı kişisel asistan.

## APK İndirme

1. Bu repoyu fork et (sağ üstten)
2. Actions sekmesine tıkla
3. "JARVIS Android APK" workflow'unu çalıştır
4. Build bitince Artifacts'tan APK'yı indir

## Özellikler

- Türkçe sesli AI asistan (Groq Llama 3.3 70b)
- ElevenLabs TTS ses çıkışı
- Takvim ve hatırlatıcı
- Hava durumu
- Ders programı takibi
- Şifreli giriş

## Kurulum

APK'yı telefona indir → Bilinmeyen kaynaklara izin ver → Kur → Aç → API anahtarlarını gir
